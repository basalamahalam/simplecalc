# SimpleCalc Flutter App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a simple four-function calculator Flutter app, release-configured and documented for submission to Google Play Console under current (Nov 2026) policy.

**Architecture:** Single Flutter app, Android-only platform target. A pure-Dart `CalculatorEngine` (no Flutter dependencies) owns all arithmetic/state logic and is unit-tested in isolation; a thin `CalculatorScreen` StatefulWidget renders the display and button grid and delegates every button press to the engine. No external state-management package, no backend, no permissions.

**Tech Stack:** Flutter 3.41 / Dart 3.11 (already installed), Material 3, `flutter_launcher_icons` (dev dependency, icon generation only), Python3 + Pillow (one-off script, not a project dependency) to generate the source icon PNGs.

**Spec:** This plan's design was agreed in conversation (no separate spec file was written — the project is small enough that the brainstorming summary approved by the user serves as the spec). Key decisions carried forward:
- App name: **SimpleCalc**. Package/applicationId: **com.doughlasnichola.simplecalc** (fixed permanently once published — do not change).
- Calculator follows standard **operator precedence** (`×` `÷` evaluated before `+` `−`), e.g. `2+3×4` = `14`.
- No ads, no accounts, no network access, no analytics, no data collection of any kind.
- Deliverable includes Play Console compliance docs (`PRIVACY_POLICY.md`, `PLAY_STORE_CHECKLIST.md`) since actual submission requires the user's own developer account and signing key.

## Global Constraints

- Platform: Android only (`flutter create --platforms android`) — no iOS/web/desktop scaffolding.
- `applicationId` = `com.doughlasnichola.simplecalc`, app label = `SimpleCalc`.
- `compileSdkVersion` / `targetSdkVersion` must be ≥ 35 (Play Console's current minimum target API). Flutter 3.41's default is 36 — verify, do not lower it.
- `minSdkVersion` default (24) is acceptable — do not raise or lower without reason.
- Zero Android permissions declared beyond Flutter's own template defaults.
- No new runtime dependencies beyond `flutter_launcher_icons` (dev-only, build-time).
- Every arithmetic result is formatted through one function; no ad-hoc `toString()` calls on doubles in the UI layer.
- All work committed to git with small, logical commits (git repo must be initialized — none exists yet).

## Review Focus

- **Pressing an operator twice in a row** (`5 + × 3 =`) — a reasonable user expects the second operator to simply replace the first, not crash or silently drop a token. (Task 2)
- **Pressing `=` with a trailing, unresolved operator** (`5 + =`) — must not throw or return garbage; staying on the current display unchanged is the expected safe behavior. (Task 2)
- **Leading zeros while typing a number** (`0`, `0`, `5` → should read `5`, not `005`). (Task 2)
- **Typing `.` as the very first character of a number** (`.`, `5` → should read `0.5`, not `.5`). (Task 2)
- **Division by zero, including `0 ÷ 0`** — both must show `Error` without crashing, and the very next digit press must cleanly recover (clear the error) rather than appending to a broken state. (Task 2)

### Task 2: Calculator engine (pure Dart logic)

**Files:**
- Create: `lib/calculator_engine.dart`
- Test: `test/calculator_engine_test.dart`

**Interfaces:**
- Produces: `class CalculatorEngine` with:
  - `String get display` — current expression/number/result as shown to the user; `''` means "nothing typed yet" (UI maps this to `0`).
  - `bool get hasError`
  - `void inputDigit(String digit)`
  - `void inputDecimal()`
  - `void inputOperator(String op)` — `op` is one of `'+'`, `'-'`, `'×'`, `'÷'`
  - `void inputPercent()`
  - `void backspace()`
  - `void clear()`
  - `void evaluate()`

**Design notes (pin the algorithm; implementer writes the code):**
- Internal state: a `List<String> _tokens` (alternating number-strings and operator-strings) plus `String _currentNumber` (the number currently being typed, not yet committed to `_tokens`).
- `inputOperator`: if `_currentNumber` is non-empty, commit it and push the operator onto `_tokens`, then clear `_currentNumber`. If `_currentNumber` is empty and `_tokens` is non-empty, **replace** the last operator in `_tokens` with the new one (covers "pressing an operator twice"). If both are empty, only `'-'` is accepted, starting a negative number (`_currentNumber = '-'`); other operators are ignored.
- Leading zeros: appending a digit to `_currentNumber` must collapse a lone leading `'0'` (so `0`,`0`,`5` → `'5'`), except when the next char is `'.'`.
- Leading decimal: if `_currentNumber` is empty (or just `'-'`) when `inputDecimal()` is called, prepend `'0'` first (so it becomes `'0.'` or `'-0.'`).
- `evaluate()`: build the full token list (`_tokens` + `_currentNumber` if non-empty). If the list ends in an operator (trailing operator, no final operand) or is otherwise incomplete, do nothing (display stays as-is). Otherwise evaluate in two passes: first pass resolves all `×`/`÷` left-to-right, second pass resolves `+`/`-` left-to-right on what remains. Any division by zero (including `0 ÷ 0`) sets `hasError = true` and `display` to `'Error'`. On success, reset `_tokens` to empty and `_currentNumber` to the formatted result, so the next digit/operator press chains from it.
- Formatting: round to 10 decimal places, strip trailing zeros and a trailing `.` if present, so `10 ÷ 2` → `'5'` and `1 ÷ 3` → `'0.3333333333'`.
- Any `inputDigit` call while `hasError` is true must first fully reset state (as `clear()` does) before inserting the digit.
- `backspace()`: if `_currentNumber` is non-empty, drop its last character. Otherwise, if `_tokens` is non-empty, pop its last element (an operator) off, with no further change (lets the user pick a new operator).
- `inputPercent()`: parse `_currentNumber` as a double, divide by 100, reformat it back into `_currentNumber` (only acts on the number currently being typed).

group('CalculatorEngine', () {

    expect(e.display, '0.5');
  });

  test('decimal input ignores a second decimal point', () {
    final e = CalculatorEngine();
    e.inputDigit('1'); e.inputDecimal(); e.inputDigit('5'); e.inputDecimal();
    expect(e.display, '1.5');
  });

  test('basic addition', () {
    final e = CalculatorEngine();
    e.inputDigit('2'); e.inputOperator('+'); e.inputDigit('3'); e.evaluate();
    expect(e.display, '5');
  });

  test('operator precedence: multiplication before addition', () {
    final e = CalculatorEngine();
    e.inputDigit('2'); e.inputOperator('+');
    e.inputDigit('3'); e.inputOperator('×');
    e.inputDigit('4'); e.evaluate();
    expect(e.display, '14');
  });

  test('pressing an operator twice replaces the previous one', () {
    final e = CalculatorEngine();
    e.inputDigit('5'); e.inputOperator('+'); e.inputOperator('×');
    e.inputDigit('3'); e.evaluate();
    expect(e.display, '15');
  });

  test('equals with a trailing operator is a no-op', () {
    final e = CalculatorEngine();
    e.inputDigit('5'); e.inputOperator('+'); e.evaluate();
    expect(e.display, '5+');
  });

  test('division by zero shows Error', () {
    final e = CalculatorEngine();
    e.inputDigit('5'); e.inputOperator('÷'); e.inputDigit('0'); e.evaluate();
    expect(e.display, 'Error');
    expect(e.hasError, true);
  });

  test('zero divided by zero shows Error', () {
    final e = CalculatorEngine();
    e.inputDigit('0'); e.inputOperator('÷'); e.inputDigit('0'); e.evaluate();
    expect(e.display, 'Error');
  });

  test('typing a digit after an error resets cleanly', () {
    final e = CalculatorEngine();
    e.inputDigit('5'); e.inputOperator('÷'); e.inputDigit('0'); e.evaluate();
    e.inputDigit('1');
    expect(e.hasError, false);
    expect(e.display, '1');
  });

  test('percent converts the current number', () {
    final e = CalculatorEngine();

  test('backspace on an empty current number removes the last operator', () {
    final e = CalculatorEngine();
    e.inputDigit('5'); e.inputOperator('+'); e.backspace();
    expect(e.display, '5');
  });

  test('clear resets everything', () {
    final e = CalculatorEngine();
    e.inputDigit('1'); e.inputOperator('+'); e.inputDigit('2'); e.clear();
    expect(e.display, '');
  });

  test('chaining continues from the previous result', () {
    final e = CalculatorEngine();
    e.inputDigit('2'); e.inputOperator('+'); e.inputDigit('3'); e.evaluate();

    expect(e.display, '6');

    e.inputOperator('-'); e.inputDigit('5'); e.evaluate();
    expect(e.display, '-5');
  });

  test('non-terminating division is rounded to 10 decimals, trimmed', () {
    final e = CalculatorEngine();
